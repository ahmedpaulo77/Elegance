# Élégance — Women's Fashion Landing Page

A responsive, elegantly designed fashion boutique landing page built with pure HTML & CSS. No frameworks, no JavaScript dependencies — just clean, modern code.

## 🔗 Live Demo

> _Add your GitHub Pages link here after deploying:_
> [https://your-username.github.io/elegance-boutique](https://your-username.github.io/elegance-boutique)

---

## ✨ Features

- **Sticky navigation** with blur/glassmorphism effect
- **Hero section** with animated stats
- **Category grid** with hover zoom effects
- **Product cards** with sale badges and smooth hover animations
- **Promotional banner** with dark theme
- **Responsive layout** — works on mobile, tablet, and desktop
- **Google Fonts** integration (Cormorant Garamond + Inter)
- Clean CSS custom properties (variables) for easy theming

---

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, CSS Grid, Custom Properties, Clamp)
- Google Fonts

## 🚀 Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to **Settings** → **Pages**
3. Under **Source**, select `main` branch → `/ (root)`
4. Click **Save** — your site will be live in ~1 minute
